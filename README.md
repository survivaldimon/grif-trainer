# Гриф · Grif

**RU** · [EN](#english)

Ежедневная тренировка на электрогитаре для техничного дэт-метала, устроенная как программа в тренажёрном зале.

**Открыть:** `https://<ваш-ник>.github.io/grif-trainer/` · английская версия: `.../grif-trainer/#en`

## Идея

- **Одна программа для всех.** Тренировка определяется датой: у всех, кто открыл «Гриф» в этот день, она одинаковая. Удобно заниматься вместе с друзьями и обсуждать одно и то же.
- **Единственная настройка — время:** от 15 минут до 5 часов. При нехватке времени первыми выпадают блоки с конца плана: музыка, затем поддержка. Фокус дня остаётся всегда.
- **Темп у каждого свой.** Программа задаёт не bpm, а протокол: как найти свой чистый темп и что с ним делать на этой неделе. Одно и то же упражнение работает и для новичка, и для профи.

## Как устроена программа

| | Пн | Вт | Ср | Чт | Пт | Сб | Вс |
|---|---|---|---|---|---|---|---|
| Фокус | Ритм | Арпеджио | Левая рука | Ритм | Арпеджио | Левая рука | Связки |

- **База каждый день:** альтернейт, смена струн, перескоки, синхронизация рук, глушение.
- **Цикл 4 недели:** объём → наращивание → скорость (рывки) → разгрузка с тестами в последнее воскресенье.
- **Каждый цикл** меняется лад (фригийский, гармонический минор, уменьшённая гамма, локрийский, фригийский доминант, целотонная) и набор вариантов упражнений.
- **36 техник** с табами: от тремоло и галопов до свипа по уменьшённым септаккордам, многопальцевого теппинга и этюдов-связок.
- **Рифф дня:** одинаковые для всех условия (размер, лад, техника, ограничение) для сочинения.
- **Обязательные паузы** и правила безопасности.

## Возможности

- Поблочный таймер с сигналом и автопереходом
- Метроном: нечётные размеры с акцентами групп, деление доли, режим «рывков», автоподъём темпа
- Табы для каждого упражнения
- Тесты цикла с историей результатов (хранится только в браузере)
- Копирование тренировки дня текстом
- Русский и английский, светлая и тёмная тема, работает на телефоне

## Запуск

Это один файл `index.html` без сборки и без сервера. Его можно просто открыть в браузере.

Публикация на GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.

## Безопасность

Боль, жжение или онемение в руке — сразу стоп. Программа не заменяет преподавателя и врача.

# Grif · daily tech death guitar workout

[RU](#гриф--grif) · **EN**

A daily electric guitar workout for technical death metal, built like a gym program. *Grif* is Russian for both a guitar neck and a barbell.

**Open:** `https://<your-username>.github.io/grif-trainer/#en`

## The idea

- **One program for everyone.** The workout is set by the date: everyone who opens Grif on a given day gets the same one, so you can train alongside friends.
- **The only setting is time:** from 15 minutes to 5 hours. When time is short, blocks drop from the end of the plan: music first, then maintenance. The day's focus always stays.
- **Tempo is personal.** The program prescribes protocols, not bpm: how to find your clean tempo and what to do with it this week. The same exercise works for a beginner and a pro.

## Structure

| | Mon | Tue | Wed | Thu | Fri | Sat | Sun |
|---|---|---|---|---|---|---|---|
| Focus | Rhythm | Arpeggios | Left hand | Rhythm | Arpeggios | Left hand | Combos |

- **Daily base:** alternate picking, string changes, string skipping, hand sync, muting.
- **4-week cycle:** volume → build → speed (bursts) → deload with tests on the last Sunday.
- **Every cycle** brings a new scale (Phrygian, harmonic minor, diminished, Locrian, Phrygian dominant, whole tone) and a new set of exercise variants.
- **36 techniques** with tabs, from tremolo and gallops to diminished sweeps, multi-finger tapping and combination études.
- **Riff of the day:** the same songwriting conditions for everyone (meter, scale, technique, constraint).
- **Mandatory breaks** and safety rules.

## Features

- Block timer with a chime and auto-advance
- Metronome: odd meters with group accents, subdivisions, burst mode, auto tempo ladder
- Tabs for every exercise
- Cycle tests with result history (stored in your browser only)
- Copy today's workout as text
- Russian and English, light and dark themes, works on phones

## Running it

A single `index.html` with no build step and no server. Open it in any browser.

GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.

## Safety

Pain, burning or numbness in the hand: stop right away. This program is not a substitute for a teacher or a doctor.
