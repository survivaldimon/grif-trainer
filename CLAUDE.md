# Гриф (Grif): контекст для Claude

Веб-приложение с ежедневной тренировкой на электрогитаре для техничного дэт-метала.
Репозиторий: https://github.com/survivaldimon/grif-trainer. Публикуется через GitHub Pages из `main`, папка `/ (root)`.
Есть копия приложения как артефакт на claude.ai, но источник правды — этот репозиторий.

## Как работать с автором
- Пишет по-русски, отвечать по-русски.
- Перед крупными изменениями предложить план и задать вопросы. Решения должны быть продуманы, а не поверхностны.
- Коммитить небольшими осмысленными коммитами. Push только после явного «ок».
- Ничего из раздела «Ограничения и идеи» не делать без решения автора.

## Концепция (не нарушать без согласия автора)
- Один универсальный тренер для всех. Без онбординга, профилей и уровней.
- Тренировка определяется только датой: у всех, кто открыл приложение в этот день, она одинаковая.
- Единственная персонализация — время сессии: 15, 30, 45, 60, 90, 120, 180, 240, 300 минут.
- Уровень масштабируется только темпом. Программа задаёт не bpm, а протокол: чистый темп = максимум без ошибок и зажима, рабочий = на 10% ниже.
- Аналогия со спортзалом: база каждый день, сплит по фокусам, периодизация, разгрузка, тесты.

## Архитектура
Всё приложение — один файл `index.html`: без сборки и без зависимостей, кроме Google Fonts. Внутри один IIFE-скрипт, разделы по порядку:
- утилиты: `mod`, `rot`, `splitInt`, сидируемый rng (mulberry32), обёртки `lsGet`/`lsSet`;
- язык: `LANG`, `UI`, `ABOUT`, `SAFETY`, `dateText`;
- рендер табов: `renderSystem` (токены `G14`, `eh17`, `A2+E0`; `.` — пауза, `|` — тактовая черта);
- лады `MATERIALS` и генераторы `threeNps`, `npsTokens`, `oneStringSeq`;
- `EX` — 40 упражнений на русском: W0–W3 разминка, B1–B5 база, R6–R15 ритм, A16–A23 арпеджио, L24–L31 левая рука, C32–C36 связки. Упражнения с `gen:true` (B4, A21, L24, L28) генерируются по дню и ладу цикла;
- `EXEN` — английский оверлей с теми же id и тем же числом вариантов;
- `GROUPS`, `TESTS`, `PHASES`, `ALLOC`;
- `buildSession(dayIndex, T)`, `resolveEx`, рендер, таймер, метроном на Web Audio, обработчики.

Для отладки наружу торчит `window.__grif` (buildSession, dayInfo, resolveEx, ALLOC, TIMES, EX, EXEN, GROUPS, renderTab, TESTS, setLang, X, VX).

## Расписание
- Якорь — понедельник 2026-11-02, `dayIndex = 0`. День считается по локальной дате пользователя.
- Цикл 28 дней = 4 недели: Объём → Наращивание → Скорость (рывки) → Разгрузка.
- Воскресенье 4-й недели — тесты T1–T5: 15 минут сразу после разминки, минуты вычитаются из B, F, M, C, Mu по порядку.
- Фокус по дням Пн–Вс: R, A, L, R, A, L, C. База (B1 + ротация B2–B5) — каждый день.
- В разгрузочную неделю при T ≥ 45 фокус и поддержка × 0.6, освободившиеся минуты уходят в музыку.
- Пул вариантов упражнений = `cycle mod 3`. Лад цикла = `cycle mod 6`.
- До старта (`dayIndex < 0`) — «вводная неделя», лад фригийский.
- `ALLOC` задаёт минуты блоков W, B, F, M, C, Mu и паузы:
  - до 90 минут — паузы по 3 мин каждые ~25 мин;
  - от 120 минут — по 10 мин каждые ~50 мин.
- При нехватке времени сначала выпадает музыка, потом поддержка. Фокус остаётся всегда.
- Рифф дня детерминирован по дате (размер, техника, условие). Выбирается по индексам, поэтому одинаков в RU и EN.

## Инварианты (проверять после любых изменений)
- Сумма минут сегментов == T для всех T и любого дня, включая отрицательные `dayIndex`.
- Нет сегментов с 0 минут. Паузы не стоят первыми, последними или подряд.
- Каждое упражнение из `EX` хоть раз попадает в план за 6 циклов.
- У каждого id в `EX` есть `EXEN` с `name`, `goal`, `how`, `tip`; число вариантов совпадает; у каждого варианта с `note` в RU есть `note` в EN.
- В EN-интерфейсе нигде нет кириллицы.
- Табы — стандартный строй, 6 струн. Табов реальных песен нет: только собственные упражнения и этюды, на песни ссылаемся по названию.
- `localStorage` только для удобств, каждое обращение в try/catch. Ключи с префиксом `grif.`: `time`, `lang`, `bpm`, `bpmEx`, `tests`.

## Проверка
Скрипт на Playwright в `tests/` (не в `index.html`). Он:
- прогоняет `buildSession` через `window.__grif` для `dayIndex` от −7 до 168, всех T, в обоих языках, и проверяет инварианты;
- кликает по плану 5-часовой тренировки и ищет кириллицу в EN.

Прогонять перед каждым коммитом.

## Ограничения и идеи на будущее (только по решению автора)
- В табах нет ритмической записи, ритм описан текстом.
- Метроном (рывки, лестница, нечётные размеры) и таймер в реальном звуке толком не тестировались.
- Барабанные лупы вместо метронома отложены.
